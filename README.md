# 432Hz 睡眠音樂

以 432Hz 調音為主的助眠音樂網頁(手機使用),所有內容由 [`config.json`](config.json) 設定。

## 功能
- 曲目、分類(環境音 / 自然音 / 鋼琴 / 冥想)、播放清單「今晚好眠」、使用小提醒、關於 432Hz、免責聲明,全部讀取 `config.json`
- 3 首音樂:深海靜謐、森林夜曲、星空冥想(星空冥想有「吸氣/吐氣」呼吸引導)
- 定時關閉:15 / 30 / 45 / 60 / 90 分鐘,預設 1 小時,最後 30 秒慢慢淡出
- 曲目切換 5 秒交叉淡入淡出、夜燈模式、鎖定畫面控制、可加入主畫面(PWA)

## 音樂來源
目前曲目的 `audio_url` 是空的,會用 `generator` 欄位以 Web Audio 即時生成 432Hz 音樂(柔和、無尖銳高頻)。
若要改播真正的音檔:把 mp3 放進 `audio/` 資料夾,將 `audio_url` 設為例如 `"audio/deep-sea.mp3"`,就會改播該檔案(同樣套用定時關閉與淡出)。
`cover_url` 留空會顯示自動產生的封面;填入圖片網址即顯示圖片。

## 使用
GitHub Pages(Settings → Pages → Branch: `main` / root),手機打開網址即可。
