# 好眠 432 · 睡前音樂

手機用的睡前音樂網頁,所有音樂都以 **A = 432Hz** 調音,用 Web Audio 即時生成(不需要音檔、每次都不重複)。

## 功能
- 4 首「432Hz 深度睡眠・α波」風格音樂:清理負面情緒、鬆弛肌肉、放下壓力、星空冥想(柔和長音 + 輕柔琴聲 + α 波雙耳節拍 + 低沉自然聲,無尖銳高頻與突然的聲音)
- 定時關閉:15 分 ~ 3 小時,預設 **1 小時**,也可用滑桿自訂;結束前會慢慢淡出
- 夜燈模式:螢幕全黑只顯示時間與剩餘時間,音樂持續播放
- 鎖定畫面播放控制(Media Session)、可「加入主畫面」當 App 使用(PWA)
- 記住上次的音樂、音量、定時設定

## 使用
開啟 GitHub Pages(Settings → Pages → Branch: `main` / root),用手機打開網址即可。
